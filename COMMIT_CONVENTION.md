## Prefix

| Type        | Use                                                 |
|-------------|-----------------------------------------------------|
| `feat`      | New function                                        |
| `fix`       | Bug fix                                             |
| `docs`      | Changes in documentation (README, docstrings, etc.) |
| `style`     | Format, lint, spaces, without altering logic        |
| `refactor`  | Refactor without altering logic                     |
| `test`      | Added or modified test files                        |
| `chore`     | Minor changes or maintenance                        |
| `ci`        | CI/CD Configurations changes                        |
| `perf`      | Performance improvement                             |


## Examples

feat: add endpoint to request ...

fix: Validation correction for the mobile phone number

docs: update README

refactor: The business logic was separated into classes

style: add colors in index.html

test: add validation in the request

chore: add static images

ci: optimize docker build cache... 

pref: Optimize query to retrieve all registers
